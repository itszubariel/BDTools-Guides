Components V2 Guide.

A beginner-friendly guide to Components V2 in BDFD

Parents

Components that hold children

Display

Visual elements inside parents

Interactive

Elements users click or select

All Functions

Parents

$addContainer

Adds a container to hold other components

$addSection

Adds a section with an accessory button or thumbnail

$addActionRow

Adds an action row to hold buttons and select menus

$addMediaGallery

Adds a media gallery to hold images and videos

Display

$addTextDisplay

Adds a text display to containers or sections

$addSeparator

Adds a visual separator between components

$addThumbnail

Adds a thumbnail image to a section

 $addMediaGalleryItem

Adds an image or video to a media gallery

Interactive

$addButtonCV2

Adds a button to an action row or section

$addStringSelect

Adds a string select menu with custom options

$addStringSelectOption

Adds an option to a string select menu

 $addUserSelect

Adds a user select menu

 $addRoleSelect

Adds a role select menu

 $addMentionableSelect

Adds a mentionable select menu (users and roles)

Getting Started

New to Components V2?

If you're completely new, start with these two functions:

  1. $addContainer: the top-level container that holds everything
  2. $addTextDisplay: the simplest display component
